SDK bridge

The Godot HTML5 build loads /dapp/play/sdk-bridge.js, which exposes window.MspcDappBridge with helpers:

  • sendEvent(name, player_id, context_id, signed_data, payload) → POST /dapp/api/fb_event
  • fetchSocialGraph(player_id) → GET /dapp/api/social_graph
  • setToken(t) / loadToken() → bearer plumbing via localStorage

FBInstantGamesConnector.record_event(…) routes events to the social graph; missing module degrades gracefully. Every event crystal-anchors at tier='fb_event'.
